# Stack

- Cloudflare Workers / D1 / custom domain
- Hono and Hono JSX
- Vite+ with the Cloudflare Vite plugin
- Browser-native ZIP parsing, `DecompressionStream`, IndexedDB
- TypeScript 7, Vitest, oxlint, oxfmt

Authentication is intentionally absent. The archive never becomes server-side product data, so an identity layer would add cost without protecting a server-owned record.
